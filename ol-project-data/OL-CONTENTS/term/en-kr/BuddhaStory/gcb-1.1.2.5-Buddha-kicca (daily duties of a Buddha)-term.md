# 신규 용어집 - gcb-1.1.2.5-Buddha-kicca (daily duties of a Buddha)

* Tārayitu:
  - 1차 : Tārayitu(남을 건네주는 자)
  * 2차 : 남을 구원하여 건네주는 성자
* Tarita:
  - 1차 : Tarita(건너간 자)
  * 2차 : 스스로 혹은 도움을 받아 건너간 성자
* saṃsāra:
  - 1차 : saṃsāra(윤회)
  * 2차 : 태어나고 죽는 고통의 순환(윤회)
* Paṭivedha:
  - 1차 : Paṭivedha(통찰/체득)
  * 2차 : 진리의 깨달음
* Dhammābhisamaya:
  - 1차 : Dhammābhisamaya(법의 깨달음)
  * 2차 : 진리를 깨달아 앎
* ābhisamācārika:
  - 1차 : ābhisamācārika(행실에 관한 미세한 계율)
  * 2차 : 수행자의 일상적인 예절과 행동 수칙
* nāma:
  - 1차 : nāma(정신)
  * 2차 : 정신 작용
* rūpa:
  - 1차 : rūpa(물질)
  * 2차 : 물질적인 몸
* Sāvaka-Bodhisattas:
  - 1차 : Sāvaka-Bodhisattas(성문 보살)
  * 2차 : 깨달음을 구하는 성문 수행자
* Sotāpatti:
  - 1차 : 예류과(Sotāpatti)
  * 2차 : 첫 번째 성자의 단계(예류과)
* phala-samāpatti:
  - 1차 : 과등지(phala-samāpatti)
  * 2차 : 깨달음의 평온함을 누리는 명상(과등지)
* nirodha-samāpatti:
  - 1차 : 멸진등지(nirodha-samāpatti)
  * 2차 : 모든 생각과 감정이 멈춘 깊은 명상(멸진등지)
* payatta:
  - 1차 : payatta(지극한 근면/정진)
  * 2차 : 부처님의 끊임없는 정진
* bhaga:
  - 1차 : bhaga(공덕/덕성)
  * 2차 : 부처님의 신성한 덕성
