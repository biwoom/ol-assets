## 3차 추가 판단

* Dhamma: 법(Dhamma)
  * 2차 : 문맥에 따라 법 또는 가르침
  * 3차 본문 : 가르침(Dhamma), 삼보 나열에서는 가르침
  * 원용어 추적 : Dhamma, 최초 1회 괄호 병기 및 누적 용어집의 기본형 `법` 참조
  * 검토: 누적 용어집의 기본형은 `법`이나, 이 문서의 예경문에서는 일반 독자 가독성을 위해 `가르침`을 본문 표기로 삼음. 교학적 정식 명칭이 필요한 대목에서는 `법`으로 되돌릴 수 있음.
* Sangha: 승가(Sangha)
  * 2차 : 승가
  * 3차 본문 : 승가(Sangha), 첫 설명에서 성스러운 제자들의 공동체로 풀이
  * 원용어 추적 : Sangha
  * 검토: 삼보 용어이므로 `승가`를 유지하되, 첫 본문 설명에서 독자 이해를 돕는 풀이를 붙임.
* sīla / samādhi / paññā: 지계 / 선정 / 지혜
  * 2차 : 지계, 선정, 지혜
  * 3차 본문 : 계행(*sīla*), 마음의 집중(*samādhi*), 지혜(*paññā*)
  * 원용어 추적 : sīla, samādhi, paññā, 본문 괄호 병기
  * 검토: `지계`와 `선정`은 전문성이 높아 3차 본문에서는 쉬운 표현을 앞세움. 다만 삼학의 전통 용어는 괄호와 리뷰 노트에서 추적 가능하게 둠.
* Path / Fruition / Nibbāna: 도 / 과 / 열반
  * 2차 : 도와 과, 열반(Nibbāna)
  * 3차 본문 : 성자의 길(Path)과 그 결실(Fruition), 그리고 열반(Nibbāna)
  * 원용어 추적 : Path, Fruition, Nibbāna
  * 검토: `도와 과`만으로는 일반 독자 이해가 어렵기 때문에 뜻풀이를 앞세움. 교학적 대응은 괄호 병기로 보존함.
