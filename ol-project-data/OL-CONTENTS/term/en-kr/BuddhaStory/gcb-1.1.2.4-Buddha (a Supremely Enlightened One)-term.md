# 신규 용어집 - gcb-1.1.2.4-Buddha (a Supremely Enlightened One)

* magga-ñāṇa:
  - 1차 : 도(道)의 지혜(magga-ñāṇa)
  * 2차 : 깨달음의 길을 아는 지혜
* sabbaññuta-ñāṇa:
  - 1차 : 일체지(sabbaññuta-ñāṇa)
  * 2차 : 모든 것을 아는 지혜
* Sammā-sambuddha:
  - 1차 : Sammā-sambuddha(정등각자)
  * 2차 : 완전한 깨달음을 이룬 부처님(정등각자)
* Pacceka Buddha:
  - 1차 : Pacceka Buddha(벽지불)
  * 2차 : 홀로 깨달은 벽지불
* Sāvaka-Bodhiñāṇa:
  - 1차 : Sāvaka-Bodhiñāṇa(성문의 깨달음에 대한 지혜)
  * 2차 : 가르침을 듣고 깨달은 제자의 지혜
* Sāvaka-Buddha:
  - 1차 : Sāvaka-Buddha(성문각자)
  * 2차 : 가르침을 듣고 깨달은 제자(성문각자)
* Dasabalañāṇa:
  - 1차 : Dasabalañāṇa(십력)
  * 2차 : 부처님의 열 가지 지혜의 힘
* Anguttara Nikāya:
  - 1차 : 앙굿따라 니까야(Añguttara Nikāya)
  * 2차 : 앙굿따라 니까야
* Thānāṭṭhāna ñāṇa:
  - 1차 : 처비처지력(Thānāṭṭhāna ñāṇa)
  * 2차 : 가능한 일과 불가능한 일을 판별하는 지혜
* Kammavipāka ñāṇa:
  - 1차 : 업이숙지력(Kammavipāka ñāṇa)
  * 2차 : 지은 업과 그 결과를 아는 지혜
* Sabbatthagāminī patipadā ñāṇa:
  - 1차 : 변취행지력(Sabbatthagāminī patipadā ñāṇa)
  * 2차 : 모든 세계로 이끄는 실천 방법을 아는 지혜
* Anekadhātu Nānādhātu lokañāṇa:
  - 1차 : 다계종계세계지력(Anekadhātu Nānādhātu lokañāṇa)
  * 2차 : 세상의 다양한 요소들을 아는 지혜
* Nānādhimuttikata nāṇa:
  - 1차 : 다양해지력(Nānādhimuttikata nāṇa)
  * 2차 : 중생들의 다양한 성향을 아는 지혜
* Indriya paropariyatta ñāṇa:
  - 1차 : 근상하지력(Indriya paropariyatta ñāṇa)
  * 2차 : 중생들의 능력 수준을 아는 지혜
* Jhānādi Samkilesa Vodānavuṭṭhāna ñāṇa:
  - 1차 : 선정등잡염청정기지력(Jhānādi Samkilesa Vodānavuṭṭhāna ñāṇa)
  * 2차 : 깊은 명상 상태와 그 맑아짐을 아는 지혜
* Pubbenivasa ñāṇa:
  - 1차 : 숙명통지력(Pubbenivasa ñāṇa)
  * 2차 : 전생을 기억하는 지혜
* Cutūapāta ñāṇa:
  - 1차 : 사생지력(Cutūapāta ñāṇa)
  * 2차 : 중생의 태어남과 죽음을 아는 지혜
* Dibbacakkhu ñāṇa:
  - 1차 : 천안통지력(Dibbacakkhu ñāṇa)
  * 2차 : 신성한 눈(천안)으로 꿰뚫어 보는 지혜
* Āsavakkhaya ñāṇa:
  - 1차 : 누진통지력(Āsavakkhaya ñāṇa)
  * 2차 : 모든 번뇌를 없애는 지혜
* Arahantta-magga ñāṇa:
  - 1차 : 아라한도지(Arahantta-magga ñāṇa)
  * 2차 : 아라한의 깨달음에 이르는 지혜
