# 신규 용어 후보 - gcb-1.1.2.2-Bodhisatta (a future Buddha).md

* Magga-ñāṇa: 도의 지혜 (道智)
  * 2차 : 도의 지혜
  * 3차 본문 : 도(道)의 네 가지 지혜(Magga-ñāṇa)
  * 원용어 추적 : Magga-ñāṇa, 최초 1회 괄호 병기
  * 검토: 핵심 수행 용어이므로 `도의 네 가지 지혜`를 유지하고 원어를 병기함.
* Sabbaññuta-ñāṇa: 일체지 (一切智)
  * 2차 : 일체지
  * 3차 본문 : 일체지(Sabbaññuta-ñāṇa)
  * 원용어 추적 : Sabbaññuta-ñāṇa, Sabbaññū, 각주 병기
  * 검토: 부처님의 앎을 가리키는 핵심 용어이므로 `일체지`를 유지함. 각주에서 `一切智者` 표기를 바로잡음.
* Bodhi: 깨달음 (菩提)
  * 2차 : 깨달음
  * 3차 본문 : 깨달음(Bodhi)
  * 원용어 추적 : Bodhi, 최초 1회 괄호 병기
  * 검토: 일반 독자에게 `깨달음`이 적절하므로 한역 `보리`는 본문 전면에 두지 않음.
* Sammā-Sambodhi: 삼마삼보디 (무상정등각, 無上正等覺)
  * 2차 : 정등각(正等覺) 또는 삼마삼보디
  * 3차 본문 : 무상정등각(Sammā-Sambodhi, 정등각)
  * 원용어 추적 : Sammā-Sambodhi
  * 검토: 세 가지 깨달음의 첫 항목이므로 전통 용어를 유지하고 원어를 병기함.
* Pacceka-Bodhi: 빠쩨까보디 (벽지불의 깨달음, 辟支佛의 깨달음)
  * 2차 : 벽지불의 깨달음
  * 3차 본문 : 독각의 깨달음(Pacceka-Bodhi, 벽지불의 깨달음)
  * 원용어 추적 : Pacceka-Bodhi
  * 검토: `독각`을 앞세우고 전통 한역 `벽지불`을 괄호에 보존함.
* Sāvaka-Bodhi: 사와까보디 (성문/제자의 깨달음, 聲聞의 깨달음)
  * 2차 : 제자의 깨달음
  * 3차 본문 : 제자의 깨달음(Sāvaka-Bodhi, 성문의 깨달음)
  * 원용어 추적 : Sāvaka-Bodhi
  * 검토: 일반 독자에게 `제자`가 더 쉽고, `성문`은 괄호로 추적함.
* Sammā-Sambodhisattas: 삼마삼보살 (미래의 정등각자)
  * 2차 : 미래의 정등각 부처님
  * 3차 본문 : 정등각의 보살(Sammā-Sambodhisattas), 미래의 정등각 부처님
  * 원용어 추적 : Sammā-Sambodhisattas
  * 검토: 보살 유형 구분을 위해 원어를 보존하되 본문은 뜻풀이 중심으로 처리함.
* Pacceka-Bodhisattas: 빠쩨까보살 (미래의 독각불/벽지불)
  * 2차 : 미래의 벽지불
  * 3차 본문 : 독각의 보살(Pacceka-Bodhisattas), 미래의 벽지불
  * 원용어 추적 : Pacceka-Bodhisattas
  * 검토: `독각`과 `벽지불`을 함께 추적함.
* Sāvaka-Bodhisattas: 사와까보살 (미래의 성문/제자 보살)
  * 2차 : 미래의 제자
  * 3차 본문 : 제자 보살(Sāvaka-Bodhisattas), 미래의 제자
  * 원용어 추적 : Sāvaka-Bodhisattas
  * 검토: `제자`를 본문 전면에 두고 성문 계열 원어를 보존함.
* Paññādhika: 빤냐디까 (지혜가 뛰어난 보살, 智慧增上)

  * 3차 본문 : 지혜가 뛰어난 보살(Paññādhika 보살)
  * 원용어 추적 : Paññādhika
  * 검토: 세 유형 중 하나로 반복되므로 같은 표기를 유지함.
* Saddhādhika: 사다디까 (믿음이 뛰어난 보살, 信仰增上)

  * 3차 본문 : 믿음이 뛰어난 보살(Saddhādhika 보살)
  * 원용어 추적 : Saddhādhika
  * 검토: `신심`보다 일반적인 `믿음`을 기본 표기로 삼음.
* Viriyādhika: 위리야디까 (정진이 뛰어난 보살, 精進增上)
  * 2차 : 정진이 뛰어난 보살(Viriyādhika 보살)
  * 3차 본문 : 정진이 뛰어난 보살(Viriyādhika 보살)
  * 원용어 추적 : Viriyādhika
  * 검토: 수행 용어로 `정진`을 유지함.
* Pāramidawgan Pyo: 빠라미도가 뾰 (아신 실라왐사 장로의 대서사시)

## 3차 추가 판단

* pāramī / pāramitā: 바라밀
  * 2차 : 바라밀(pāramī, 완성)
  * 3차 본문 : 바라밀(pāramī, 완성), 각주에서 pāramitā 병기
  * 원용어 추적 : pāramī, pāramitā
  * 검토: 한국 불교 독자에게 익숙한 `바라밀`을 유지하고, 처음 설명에서만 뜻풀이를 붙임.
* asaṅkhyeyya / kappa: 아승기 / 겁
  * 2차 : 아승기, 겁
  * 3차 본문 : 아승기, 겁
  * 원용어 추적 : asaṅkhyeyya, kappa, 각주 병기
  * 검토: 전통 시간 단위이므로 현대 수치 환산을 본문에 넣지 않음. `asaṅkhyeyya`의 10^140 설명은 각주에만 둠.
* abhiññā / paṭisambhidā: 신통력 / 무애해
  * 2차 : 신통력, 무애해
  * 3차 본문 : 여섯 가지 신통력(*abhiññā*)과 네 가지 무애해(*paṭisambhidā*)
  * 원용어 추적 : abhiññā, paṭisambhidā, 각주 세부 목록
  * 검토: 전문성이 높은 용어라 본문 최초 1회 원어 병기 후 각주에서 세부 설명을 유지함.
